# team_structure_research

Decision-support site and full research record on organization design for a ~140-person data organization inside a large media/streaming company. The central question: what charter should the India site have — full domain ownership, platform/capability ownership, a graduating extension model, or a hybrid — and what does that imply for the whole org?

**Status:** Phase 0 — repo setup. This README is rewritten at Phase 5 with the repo map, build notes, and findings summary.

## Layout
- `/docs` — the published site (GitHub Pages serves `main:/docs`). Identifying details are genericized here.
- `/research` — research reports, synthesis, recommendation memo.
- `/reviews` — every review cycle's critiques and responses.
- `/site-plan.md` — site information architecture and design plan.
- `/decision-memo.md` — full-context decision memo (repo only; not published).
